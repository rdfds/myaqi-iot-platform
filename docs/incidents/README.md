# Incident records

This directory holds sanitized records from actual incidents or explicitly labeled game-day exercises. There are no historical incident claims in the repository at bootstrap.

Each record should link the alert transition, affected deployment revision, investigation queries, containment action, recovery evidence, and follow-up owners without copying secrets, raw device credentials, student data, or AWS account identifiers. Use [`template.md`](template.md) and distinguish observed facts from hypotheses.
